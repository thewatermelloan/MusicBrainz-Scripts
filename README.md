# MusicBrainz Scripts

This repository is intended to provide a collection of scripts and script functions (snippets) that can be used with [MusicBrainz Picard](https://picard.musicbrainz.org/). 

### PMEDIA Removal
Edited version of [Travis Runyard's script](https://blog.travisflix.com/musicbrainz-picard-scripting-delete-all-pmedia-mp3-tags/). The only change I made was to include "P.M.E.D.I.A" in addition to the options he has after I noticed the version with .'s wasn't included.
